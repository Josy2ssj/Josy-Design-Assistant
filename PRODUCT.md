# Josy Design Assistant
## Platform
web dentro de una ventana local de Windows (modo aplicación de Microsoft Edge).
## Stack
Elección delegada explícitamente por Josy: Node.js local y JavaScript sin framework; JSON recuperable y recursos copiados. Runtime Node incluido, Microsoft Edge instalado en Windows; sin servicios remotos. Electron fue descartado tras fallar el arranque en este equipo.
## Users and purpose
Josy necesita organizar proyectos gráficos, referencias e identidades en un estudio personal, bonito y rápido. Idea → referencias → moodboard → identidad → diseño → exportación, de forma progresiva.
## Constraints
Offline por defecto. Sin cuentas ni IA automática. No modificar originales. Sesiones incrementales con pruebas y versión ejecutable. Esta sesión prioriza Inicio, proyectos, moodboards e identidades. No implementar toda la visión.
## Brand commitments
Minimalismo premium inspirado en principios de Apple, sin copiar macOS: espacio, jerarquía, sombras sutiles, herramientas contextuales, tema claro y oscuro. Contenido protagonista. Español.
## Evidence
Brief del usuario; no hay logos ni imágenes de marcas proporcionados. La biblioteca comienza vacía.
